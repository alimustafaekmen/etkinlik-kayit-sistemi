# Haftalık Kanban ekran görüntüleri

Her hafta sonu panonun tamamını gösteren bir ekran görüntüsü buraya kaydediliyor:

```
hafta-01_2026-11-29.png
hafta-02_2026-12-06.png
hafta-03_2026-12-13.png
hafta-04_2026-12-20.png
hafta-05_2026-12-27.png
```

Görüntüde `Todo`, `In Progress`, `(Issues / Blocked)` ve `Done` sütunları açıkça görünmeli. Klasör her hafta
zip'lenip OnlineBeykoz'a "Kanban Geçmişi" (`Kanban_History_Week_01-0N.zip`) ve güncel görüntü (`Kanban_Week_0N.png`)
olarak yükleniyor (bkz. `../README.md`).
